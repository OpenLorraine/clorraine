# Changelog

## 1.3.0

- Published on the Visual Studio Marketplace; the Clorraine installers now
  install and update the extension from there.
- Windows 11 x64 is supported alongside Linux x86_64.
- New `clorraine.driverPath` command, used by the starter project's tasks so
  they work on any machine with Clorraine installed.
- Missing-tool errors offer **Open install guide**.
- A notice appears once per session when the installed Clorraine tools are
  older than the extension.

## 1.2.0

- First release: compiler diagnostics, hover, go to definition, completion,
  document symbols, and syntax highlighting for `.clo` files.
- **Build**, **Run**, and **Run in FS-UAE** for the active program.
