# LorraineOS on YouTube

Channel setup and upload guide for the LorraineOS / Clorraine demos. Creating the
channel and uploading are manual steps (they need your Google account); everything
else here is generated by the repository.

## 1. Create the channel (manual)

1. Sign in to YouTube with the Google account that should own the channel.
2. **Create a channel** → name: **LorraineOS**.
3. Choose a handle. Candidates, in order of preference:
   - `@LorraineOS`
   - `@LorraineOSProject`
   - `@ClorraineLang`
4. Complete verification if YouTube asks, and accept the Terms of Service.

## 2. Branding assets

Generate the images (host-only; needs Chrome):

```sh
make channel-assets
```

Outputs, with YouTube's sizes:

| File | Size | Use |
|------|------|-----|
| `build/channel/banner.png` | 2560×1440 | Channel banner (safe area 1546×423 holds the text) |
| `build/channel/avatar.png` | 800×800 | Channel avatar (cropped to a circle) |
| `build/channel/thumbnail.png` | 1280×720 | Video thumbnail |

- **Customization → Branding:** upload the banner and avatar.
- **Customization → Basic info:** paste the description below and the links.

The pages behind these images live in `tools/demo/assets/channel/`; edit them and
re-run `make channel-assets` to change the look.

## 4. Video: the Clorraine demo

Render the demo for upload at 1920×1080:

```sh
make demo-youtube
```

This writes `demo/demo-full-1080.mp4` (the story, 16:9 with the 1100×700 design
pillarboxed) and `demo/emulator-1080.mp4`. For the repository media (README gif,
poster), run `make demo` instead; it stays at 1100×700. Both are gitignored.

## Notes

- The demo renders at 1100×700 for the repository and at 1920×1080 for upload
  (`make demo-youtube`); the high-resolution render pillarboxes the design, so the
  cards, code, and captions are crisp.
- Emulator chapters are captured at 960×540 and are slightly soft when scaled up.
