**AR-8 (complexity escalation — approval evidence):**

```text
Original goal: release every OS resource the hosted-amiga runtime acquired, on every exit (normal, fault, panic, Ctrl-C) — AR-1, AR-2
Extra system or support code: a shim resource registry (one record list walked by an atexit hook)
Why it may be needed: about 45 handle kinds with many live instances each; suffix files exist only on hosted-amiga, so a central walker in the base shim cannot name their releases on hosted-amiga-13
Evidence: compiler/src/profile.rs:18-28,144-149; compiler/runtime/shim_hosted_amiga.c:229, :3000, :3011, :3025; A500 Guru 00000004 and A1200 Software Failure 8000 0004 reproduced by the 9.2.4 verifier
Smallest solution that still works: per-kind static lists plus a hand-written cl_release_all() in a fixed per-kind order (challenger: not smaller — ~45 lists, the same ~70 site edits, wrong order for several screens each with windows, needs #ifdef/hook plumbing for suffix kinds)
Extra cost: about 150-250 lines in shim_hosted_amiga.c; one register/unregister call at about 70 acquire/release sites in 7 shim files; about 10 bytes m68k per site, paid only by programs using the API; every new handle kind must register (review item)
Independent verdict: Simplify — registry for owned handles only; fixed phases for interrupt servers (existing static slots), workers (non-waiting removal), and lazy library bases (static table, shim-opened only); node embedded in wrapper structs, side records for raw OS pointers; atexit installed on first registration
Direct user decision: approved larger (simplified as the challenger recommended)
```

**AR-9 rules:** (1) pop each record before its release; a walking flag makes a fault, panic, or break during the walk print its line, finish the remaining records, and leave with `_exit(20)` (libnix re-runs atexit hooks on a nested `exit`); (2) a typed release thunk `static void cl_release_<kind>(void *)` per kind (casting the BPTR/Library deleters fails `-Werror`); (3) unregister where the resource is really freed or handed off — `cl_window_destroy`, `cl_task_join_record`, `cl_put_msg`, ARexx send/reply, the copper move into a Display — keyed by record, not pointer value; (4) when a side record or the `atexit` install fails, the acquire releases what it just got and returns its existing failure (null, or E1 where it already traps); (5) libc-managed resources (`File` via `fopen`, malloc buffers) are not registered; (6) workers are removed at exit with Forbid/RemTask/Permit, FreeSignal, FreeMem — never the joining drop; (7) worker detection compares `FindTask(NULL)` with recorded worker task pointers and never dereferences `tc_UserData`; (8) a worker's panic text is printed by the parent before `RemTask`; (9) library bases are closed only when the shim's own `OpenLibrary` opened them; (10) the hook prints nothing on a clean exit.
