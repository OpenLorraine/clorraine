# API and Ownership: `std.amiga.picasso96`

> **Document**: 03-01-api.md
> **Parent**: [Index](00-index.md)

## Module

```clorraine
module std.amiga.picasso96;
```

The module belongs to `hosted-amiga`. The host, `hosted-amiga-13`, and
freestanding profiles reject it with `E11200`. Applications import typed
functions and never declare `ffi` or `unsafe` for the surface.

## Handles

| Handle | Drop | Owns |
|---|---|---|
| `RtgScreen` | `cl_rtg_close_screen` | one `struct Screen *` opened by `p96OpenScreenTagList`; the selected display ID is stored for `rtgScreenMode` |
| `RtgBitmap` | `cl_rtg_free_bitmap` | one P96 user-private `struct BitMap *` and its RastPort |

Both drops are null-safe and run exactly once. A screen and a bitmap are
independent: a bitmap may outlive the screen it was blitted to because it owns
its own P96 memory.

## Format Constants

The constants match Picasso96's `RGBFB_*` values. They describe the readback
format; applications do not need them to open a screen.

| Constant | Value | Meaning |
|---|---|---|
| `RTG_FORMAT_R8G8B8` | 2 | 24-bit RGB |
| `RTG_FORMAT_B8G8R8` | 3 | 24-bit BGR |
| `RTG_FORMAT_A8R8G8B8` | 6 | 32-bit ARGB |
| `RTG_FORMAT_A8B8G8R8` | 7 | 32-bit ABGR |
| `RTG_FORMAT_R8G8B8A8` | 8 | 32-bit RGBA |
| `RTG_FORMAT_B8G8R8A8` | 9 | 32-bit BGRA |

The surface supports 24- and 32-bit truecolor. A 24-bit request uses a packed
truecolor mode; a 32-bit request uses a true-alpha mode. A P96 mode may use
any of the matching byte orders; `rtgScreenFormat`/`rtgBitmapFormat` report
the actual value. The UAEGFX gate's screen reports
`RTG_FORMAT_B8G8R8A8` (9) and its offscreen bitmap reports
`RTG_FORMAT_A8R8G8B8` (6). The emulated Picasso IV gate reports
`RTG_FORMAT_B8G8R8` (3) for both the screen and the bitmap.

## Discovery

| API | Returns | Rules |
|---|---|---|
| `rtgBoards(): i32` | board count | 0 when P96 is absent |
| `rtgMode(width, height, depth): u32` | display ID | 0 when no matching mode; `depth` must be 24 or 32 |
| `rtgModeWidth(mode)` | `i32` | 0 for an unknown mode |
| `rtgModeHeight(mode)` | `i32` | 0 for an unknown mode |
| `rtgModeDepth(mode)` | `i32` | 0 for an unknown mode |
| `rtgModeFormat(mode)` | `i32` | P96 `RGBFB_*` value, 0 for unknown |

`rtgMode` requests `RGBFF_TRUEALPHA` at depth 32 and `RGBFF_TRUECOLOR` at
depth 24. Any other depth returns 0.

## Screen

| API | Returns | Rules |
|---|---|---|
| `openRtgScreen(width, height, depth, title): RtgScreen?` | handle | width/height 1..4096; depth 24 or 32; `title` is copied for the screen lifetime; use an empty string for none; opens quiet, title suppressed |
| `rtgScreenWidth(borrow)` | `i32` | 0 for a null handle |
| `rtgScreenHeight(borrow)` | `i32` | 0 for a null handle |
| `rtgScreenDepth(borrow)` | `i32` | 0 for a null handle |
| `rtgScreenFormat(borrow)` | `i32` | actual P96 format of the screen bitmap |
| `rtgScreenMode(borrow)` | `u32` | selected display ID |
| `closeRtgScreen(take)` | `void` | `p96CloseScreen` exactly once; also the generated drop |

The screen handle is borrowed by every accessor and drawing call. The caller
must drop the screen before process exit; the generated cleanup does that for a
lexical binding.

## Bitmap

| API | Returns | Rules |
|---|---|---|
| `allocRtgBitmap(width, height, depth): RtgBitmap?` | handle | width/height 1..4096; depth 24 or 32; `BMF_USERPRIVATE` |
| `rtgBitmapWidth(borrow)` | `i32` | 0 for a null handle |
| `rtgBitmapHeight(borrow)` | `i32` | 0 for a null handle |
| `rtgBitmapDepth(borrow)` | `i32` | 0 for a null handle |
| `rtgBitmapFormat(borrow)` | `i32` | actual P96 format |
| `rtgBitmapBytesPerRow(borrow)` | `i32` | P96 bytes-per-row; 0 for a null handle. A `BMF_USERPRIVATE` bitmap needs no lock for this query. |
| `freeRtgBitmap(take)` | `void` | `p96FreeBitMap` exactly once; also the generated drop |

A user-private bitmap is not displayable directly; it is a source for
`rtgScreenBlitBitmap` and a target for the bitmap pixel/readback calls.

## Drawing

| API | Returns | Rules |
|---|---|---|
| `rtgScreenWritePixel(borrow, x, y, color: u32)` | `bool` | false when out of bounds or null |
| `rtgScreenReadPixel(borrow, x, y)` | `u32` | 0 when out of bounds or null |
| `rtgScreenFillRect(borrow, x0, y0, x1, y1, color)` | `bool` | inclusive rectangle; false when inverted/out of bounds |
| `rtgBitmapWritePixel(borrow, x, y, color)` | `bool` | same bounds rules |
| `rtgBitmapReadPixel(borrow, x, y)` | `u32` | 0 when out of bounds or null |
| `rtgBitmapFillRect(borrow, x0, y0, x1, y1, color)` | `bool` | bounded pixel loop; area <= 1,048,576 |

Colors are ARGB (`0x00RRGGBB` for opaque colors). The shim does not expose
`SetRGB32` or a palette; truecolor modes carry their color directly.

## Blit and Readback

| API | Returns | Rules |
|---|---|---|
| `rtgScreenBlitBitmap(borrow screen, borrow bitmap, dx, dy, sx, sy, width, height)` | `bool` | copies a rectangle with `BltBitMapRastPort`; all coordinates validated |
| `rtgScreenReadPixels(borrow screen, x, y, width, height, out: u8[])` | `i32` | fills RGB bytes; returns `width * height * 3`, or -1 |
| `rtgBitmapReadPixels(borrow bitmap, x, y, width, height, out: u8[])` | `i32` | same; buffer must be at least `width * height * 3` |

The readback format is always `RGBFB_R8G8B8` (three bytes per pixel), so a P6
PPM is a direct copy after the header. The shim validates the caller's buffer
length and uses `width * 3` as its own output stride; width is capped at 4096,
so the stride stays within the signed `WORD` field in `struct RenderInfo`.

## Example

```clorraine
import { RtgScreen, RtgBitmap, openRtgScreen, rtgScreenWritePixel,
         rtgScreenReadPixel, allocRtgBitmap, rtgBitmapFillRect,
         rtgBitmapWritePixel, rtgScreenBlitBitmap, closeRtgScreen,
         freeRtgBitmap } from std.amiga.picasso96;

func draw(): i32 {
    let screenCreated: RtgScreen? = openRtgScreen(640, 480, 32, "Clorraine RTG");
    if (screenCreated == null) { return 1; }
    let screen: RtgScreen = screenCreated;
    if (!rtgScreenWritePixel(screen, 0, 0, 0x00FF0000)) { return 2; }
    let red: u32 = rtgScreenReadPixel(screen, 0, 0);

    let bitmapCreated: RtgBitmap? = allocRtgBitmap(32, 32, 32);
    if (bitmapCreated == null) { return 3; }
    let bitmap: RtgBitmap = bitmapCreated;
    rtgBitmapFillRect(bitmap, 0, 0, 31, 31, 0x000000FF);
    rtgBitmapWritePixel(bitmap, 0, 0, 0x00FFFF00);
    rtgScreenBlitBitmap(screen, bitmap, 210, 210, 0, 0, 32, 32);
    closeRtgScreen(screen);
    freeRtgBitmap(bitmap);
    return 0;
}
```
