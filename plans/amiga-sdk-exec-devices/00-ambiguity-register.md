| AR-3 | Data & state | How is a worker task created, joined, and removed on Kickstart 1.3? | `createTask(entry, stackBytes)` uses `CreateTask` at priority -1 with a static task name and an `AllocSignal(-1)` bit. | AR-4 | Behavioral gaps | How does a worker return a value without a capture? | `reportTaskResult(value)` writes to the current task's `tc_UserData` record. The shim's final `Wait(0)` is the only blocking call in the worker path; the user entry must not block. | Auto-design (delegated technical) | ✅ Resolved |
