The license is designed for the Amiga ecosystem: you can use Clorraine

## The output exception

The output exception is an additional permission under section 7 of the Apache
License. It covers source code, object code, executables, libraries,
documentation, and other results generated by the compiler, including generated
C and the portions of the runtime and standard library embedded in that output.

You may use, reproduce, modify, distribute, sublicense, and sell compiled output
under terms of your choice. You do not need to include the Apache License, the
exception, or the compiler's copyright notices in your programs.

The exception does **not** apply to the compiler itself. The compiler, its
source code, build tools, language server, and documentation remain Apache 2.0.

Third-party material included in output keeps its own license. See
[THIRD_PARTY_NOTICES.md](https://github.com/OpenLorraine/clorraine/blob/main/THIRD_PARTY_NOTICES.md).

## Independent implementation

Clorraine is an independent implementation:

- It does not include or derive from proprietary AmigaOS source code.
- It does not distribute Kickstart ROMs or Workbench media.
- It does not publish or redistribute the Amiga NDK archive.
- It builds its toolchain from pinned public upstream sources and verifies
  downloaded inputs against published checksums.

The project's own screenshots are captured from its acceptance runs. It does not
use Amiga Corporation or Hyperion logos as site branding.

## Media and the NDK

### Kickstart and Workbench

No Kickstart ROM or Workbench image is stored in the repository or shipped in a
release. The advanced acceptance gates use licensed media supplied by the person
running them.

For local development:

- `vamos` runs AmigaOS CLI binaries without a ROM.
- FS-UAE's built-in AROS replacement ROM is the default and needs no ROM file.
- To use original media, supply your own licensed Kickstart ROMs and Workbench
  disks. [Amiga Forever](https://www.amigaforever.com/) is one licensed source.

### The NDK

The SDK image builds the m68k toolchain from
[AmigaPorts/m68k-amigaos-gcc](https://github.com/AmigaPorts/m68k-amigaos-gcc)
and its pinned upstream sources. The build downloads NDK 3.2 from its public
source and verifies the checksum. Clorraine does not host, publish, or
redistribute the NDK archive or a header bundle.

If a future agreement changes this policy, the licensing page and the project
brief will be updated with the required attribution.

## Browser demo

The live First Light player uses a pinned copy of the
[Copperline](https://copperline.dev/) browser build, version **1.1.0**
(`dfb12c45c`), with its bundled AROS ROMs.

| Component | License | Where |
|---|---|---|
| Copperline browser build | GNU GPL v3.0 or later | `site/public/copperline/pkg/` |
| AROS m68k ROMs | AROS Public License | `site/public/copperline/aros/` |
| First Light ADF and save state | Clorraine output exception; AROS terms for the ROM inside the state | `site/public/demos/` |

The Copperline source is available at
[CopperlineHQ/Copperline](https://github.com/CopperlineHQ/Copperline), and the
pinned release tree is
[v1.1.0](https://github.com/CopperlineHQ/Copperline/tree/v1.1.0). The full
notices are in
[`site/public/copperline/NOTICE.md`](https://github.com/OpenLorraine/clorraine/blob/main/site/public/copperline/NOTICE.md).

The player loads locally in the browser. It does not send the demo state or any
machine data to a server. No Kickstart ROM or Workbench media is distributed;
the AROS ROM is the open-source replacement Copperline ships.
