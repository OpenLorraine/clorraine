# Screenshots

Every image on this page is a native capture from a Clorraine FS-UAE acceptance
run. None is a mockup. Some are hardware diagnostic frames, so the colours are
deliberately simple: they prove a bitplane, collision, or palette path rather
than a visual style.

## Why no Workbench screenshots?

Workbench and Kickstart screens show licensed UI. The project avoids using them
as marketing images because they can imply endorsement. The captures above are
Clorraine's own custom screens.

The advanced Workbench gates do run, but their evidence is a report line and a
native capture used for acceptance, not site branding.
